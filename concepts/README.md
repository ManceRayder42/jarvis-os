# Concepts — opt-in working rules for your CLAUDE.md

Each concept is a self-contained rule you can paste into `~/.claude/CLAUDE.md` (all
projects) or a project's `CLAUDE.md`. None is on by default. Pick what fits how you work.

| Concept | What it fixes | Parts |
|---|---|---|
| [wall-protocol](wall-protocol/) | The agent stops at the first "I can't" instead of finding a way around it | CLAUDE.md snippet, workaround map, optional `Stop` hook |

Adding a concept: one folder, a `README.md` with the snippet to paste, the problem it
fixes, and how to verify it works.
