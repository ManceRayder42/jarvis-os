Jarvis Plugin Setup

This installs a small, persistent memory layer for Claude Code and a curated set of skills on top of it — task capture, session wrap-ups, research helpers, and a place for notes that survives across sessions and across projects. Nothing here is required to use Claude Code normally; turn on what's useful and ignore the rest.

Core

Runs locally, no account or API key needed. On by default.

Core skills
Session memory, task capture, wrap-up
doneCloses out a session: writes a short note, updates memory, commits changes. No external calls.
memory-consolidationFolds recent session logs into the hub's memory files so patterns and decisions persist.
wiki-articleTurns a discovery session into a short reference article instead of losing it to scrollback.
grill-meInterviews you about a plan or design until it actually holds together.
learnCaptures book or course notes into a structured, dated learning log.

Research

Local tools plus one that talks to Google NotebookLM. On by default.

Research skills
Reading, search, synthesis
defuddleStrips a web page down to clean markdown, locally, before you read or summarize it.
qmdLocal hybrid search (keyword + embeddings) over your own markdown notes.
research-notebookDrives NotebookLM: ingests sources, asks questions, returns a cited synthesis. Needs a Google account, not a separate API key.
llm-councilNot bundled — install it yourself. Runs a decision past five independent AI advisors and synthesizes a verdict. Excellent, and free to use, but its upstream repo ships no license, so it carries no permission to redistribute. By Ole Lehmann, after Karpathy's LLM Council.

Media

Image and video generation. Off by default — these can involve a paid API key, and a free plugin shouldn't ask for a credit card in the first minute.

Media skills
Image / video generation, off by default
nano-bananaNot bundled — install it yourself. Image generation and editing, with a free tier. Its upstream plugin is AGPL-3.0, which this MIT plugin cannot absorb, so it stays a separate install rather than a copy.
media-genPhotoreal image/video generation and upscaling via fal.ai. Pay-per-use — needs your own fal.ai API key.

Hub & vault

The hub is a plain directory that holds Jarvis's memory files. A SessionStart hook injects its MEMORY.md into every Claude Code session, from any project — Claude Code's own auto-memory only loads inside a git repo, which is why this plugin doesn't rely on it.

Remote control

To reach Claude Code from your phone, use claude remote-control plus claude.ai/code. This is the default remote path: no bot token, no allowlist, nothing to configure here. It's a real feature with real limits — stated honestly, verified against the shipped CLI rather than assumed:

  • Doesn't work from inside a cloud (headless/background) session.
  • Doesn't work behind an enterprise gateway.
  • Files the agent sends during the session don't reach the phone or web viewer — text only.
  • From the phone you can change effort level and toggle "ultracode" and not much else. This is remote control of a session already running on your machine, not a way to start one from your phone — the host has to be awake with a live session for any of it to work.

Telegram (opt-in)

An alternative remote path if you want Claude reachable from a Telegram chat instead. More setup than Remote Control (a bot token, an allowlist), and running two sessions against the same bot at once will collide — so it stays off by default and off the critical path.
